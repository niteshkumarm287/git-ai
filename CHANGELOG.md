# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-13

### Added
- Initial release of git-ai
- AI-powered commit message generation using Gemini
- Conventional commit format support
- Rich terminal UI with beautiful output panels
- Interactive commit and push workflow
- Context-aware generation using git diff and commit history
- Customizable prompt template system
- Comprehensive documentation and README

### Features
- Automatic analysis of staged changes
- Recent commit history integration
- User confirmation before committing
- Error handling and validation
- Configurable diff size limits
